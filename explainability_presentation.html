Deep Learning Autoencoders: Approximates images using floating-point numbers. Small details and fine document text fonts get blurred or lost forever (CER ≈ 24.8%).

2. The Step-by-Step Encryption Pipeline

How an image transforms into secure noise and back into exact pixels.

Step 1

Integer Wavelet Decomposition (IWT)

Splits the image into 4 integer subbands (Average, Horizontal, Vertical, Diagonal) without losing fractional precision.

Step 2

Invertible Neural Coupling (INN)

Mixes the subbands using mathematical "lock-and-key" neural blocks using floor rounding to ensure perfect reversibility.

Step 3

3D Hyperchaotic Scrambler

Generates dynamic pseudo-random keystreams to XOR-substitute pixel colors and shuffle all spatial positions into colorful noise.

Step 4

RSA-2048 Envelope Packaging

Packs the SHA-256 secret seed inside an RSA asymmetric key envelope header so only the intended receiver can decrypt.

💡 Think of it Like a Rubik's Cube with a Secret Code

Imagine you have a confidential receipt. Int-WINN-Chaos takes the receipt, folds it into integer sections (Wavelets), locks it using a mathematical key (Invertible Neural Block), and then scrambles all colored tiles using a chaotic math formula (3D Hyperchaos). To an eavesdropper, it looks like a completely random, scrambled Rubik's Cube (Entropy = 7.9998). However, because every move was done using exact integer steps, the recipient can reverse every step in exact reverse order, restoring every single letter and number with zero error.
